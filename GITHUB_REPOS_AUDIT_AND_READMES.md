```markdown
# 🛒 Enterprise E-Commerce Test Automation Framework (DEPI Graduation Project)

<div align="center">

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)
![Selenium](https://img.shields.io/badge/Selenium_WebDriver-43B02A?style=for-the-badge&logo=selenium&logoColor=white)
![TestNG](https://img.shields.io/badge/TestNG-FF7F00?style=for-the-badge&logo=testng&logoColor=white)
![Maven](https://img.shields.io/badge/Apache_Maven-C71A36?style=for-the-badge&logo=apachemaven&logoColor=white)
![Allure](https://img.shields.io/badge/Allure_Reports-663399?style=for-the-badge)

<p align="center">
  <b>Comprehensive End-to-End Automated Testing Framework for Major E-Commerce Platforms (Noon, DeFacto, Seoudi Supermarket)</b>
</p>

</div>

---

## 📌 Overview
This repository contains the graduation project for the **Digital Egypt Pioneers Initiative (DEPI)** Software Testing Track. It implements an enterprise-grade automated testing solution applying the **Page Object Model (POM)** design pattern, data-driven test scenarios, robust assertions, and detailed visual test execution reports.

## 🚀 Key Testing Modules
- **Authentication & User Profiles**: Automated tests for login, registration, password recovery, and field boundary validations.
- **Search & Filter Operations**: Dynamic keyword search, product categorization, price filtering, and pagination verification.
- **Cart & Checkout Workflows**: Adding products, modifying quantities, discount coupon validations, and mock payment cycles.
- **Cross-Browser & Parallel Execution**: Configured for multi-browser execution (Google Chrome, Firefox, Microsoft Edge) via TestNG suite XML files.
- **Reporting & Artifacts**: Integration with Allure Reports and TestNG HTML reporters for defect tracking and screenshot capture on failure.

## 🏗️ Framework Architecture
```
src/
├── main/java/pages/       # Page Object Model classes
├── test/java/tests/       # Test execution classes & assertions
├── test/resources/        # Test data (JSON/Excel), testng.xml suites
└── pom.xml                # Maven dependencies & build lifecycle
```

## ⚙️ How to Run
```bash
# Clone the repository
git clone https://github.com/IbrahimAHamada27/graduation-project-from-depi.git

# Run test suites via Maven
mvn clean test

# Generate Allure Report
mvn allure:serve
```

---
👨‍💻 **Author**: [Ibrahim A. Hamada](https://github.com/IbrahimAHamada27) — QA Automation & Software Engineer
```
